# Global Satellite Analytics with Space Sustainability

## Domain
Space Technology

## Problem Statement
The increasing number of satellites has introduced challenges such as orbital congestion, space debris, and sustainability. This project analyzes a global satellite catalog to generate insights into satellite operations, orbital characteristics, and space sustainability using data analytics techniques.

## Dataset

- File: current_catalog.csv
- Rows: 16,649
- Columns: 19
