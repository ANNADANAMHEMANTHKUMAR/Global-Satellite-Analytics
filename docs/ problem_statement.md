# Problem Statement

## Business Problem

The rapid growth of satellites in Earth orbit has increased challenges related to orbital congestion, space debris, operational monitoring, and long-term sustainability. Existing public satellite catalogs primarily focus on technical orbital parameters but lack integrated analytical features that support operational decision-making.

This project enriches the satellite dataset with additional analytical features to provide insights into satellite operations, orbital distribution, congestion risk, satellite lifetime, and sustainability.

---

# Success Metrics

The project will be considered successful if it can:

- Analyze satellite distribution across orbital regions.
- Identify congestion patterns.
- Study satellite operational lifetime.
- Compare countries by satellite ownership.
- Measure orbital characteristics.
- Build an interactive Power BI dashboard.
- Generate meaningful business insights using SQL, Excel, Python, and Power BI.
